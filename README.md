# SQL-Data-Analysis-Task-2

# SQL Data Analysis Internship – Task 2 📊

This project is part of the **SQL Data Analysis Internship (Task 2)**.
It extends a Student Management Database by adding **Courses** and **Enrollments** tables
and performs analytical queries to extract insights.

---

## 📌 Objectives
- Extend the existing student database
- Understand table relationships (one-to-many)
- Practice SQL joins, aggregations, and grouping
- Analyze student performance by course

---

## 🗄 Database Schema
### Tables Used
- **students** (id, name, age)
- **courses** (id, name)
- **enrollments** (student_id, course_id, grade)

---

## 🛠 SQL Features Used
- INNER JOIN
- GROUP BY
- AVG()
- ORDER BY
- LIMIT
- COUNT()

---

## 📊 Queries Implemented
1. List all students enrolled in each course  
2. Find average grade per course  
3. Find top 3 students overall  
4. Count students who failed (grade < 40)

---

## 📁 Files in This Repository
- `SQL_Data_Analysis_Task_2.sql` → Complete schema + queries
- `SQL_Task_2_Output.pdf` → Query outputs (formatted)

---

## ▶ How to Run
1. Open MySQL / PostgreSQL / DB Fiddle  
2. Copy and run `SQL_Data_Analysis_Task_2.sql`  
3. View results or refer to the output PDF
